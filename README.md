# 고객ON 데스크톱 릴리스

이 저장소는 고객ON 데스크톱 앱의 설치 파일과 자동 업데이트 메타데이터를 공개 배포하기 위한 전용 저장소입니다.

애플리케이션 소스 코드는 비공개 저장소에서 관리합니다.

새 릴리스는 코드 서명 없이 Windows x64 설치 파일을 배포합니다. 릴리스 빌드는 비공개 저장소의 `release-X.Y.Z` 브랜치와 동일한 태그가 가리키는 고정 커밋에서 생성됩니다. 빌드 로그는 공개되지만 비공개 소스와 빌드 산출물은 Actions 아티팩트나 캐시로 보관하지 않습니다.

공개 저장소의 수동 Actions 실행은 dry-run 검증만 허용합니다. 실제 publish는 비공개 저장소가 브랜치, annotated tag, 패키지 버전, SHA, 열린 릴리스 PR을 확인한 뒤 보내는 `desktop-release-publish` 이벤트로만 시작합니다.
